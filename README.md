## The story

`main.py` writes a single Wi-Fi network name of at most 32 characters to
`/output/entry.txt` — one that lands a joke and hints at a whole story:

> **DadChangedPasswordAfterDivorce**

Thirty characters, one little divorce drama: Dad, the split, and the Wi-Fi
password changed as a weapon. A stranger reading it in a network list gets
the whole story in one glance.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

Stdlib only, deterministic — the same 30 bytes on every run.
